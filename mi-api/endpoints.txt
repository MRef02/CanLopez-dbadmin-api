

### Get api status
GET http://localhost:3000/api/status

### Get users
GET http://localhost:3000/api/users

### Get user by id
GET http://localhost:3000/api/users/1


# productosº

### 1. GETBYID - Obtener producto por ID
GET http://localhost:3000/api/producto/1

### 2. GETALL - Obtener todos los productos
GET http://localhost:3000/api/productos

### 3. POST - Crear producto
POST http://localhost:3000/api/producto
Content-Type: application/json

{
  "nombre": "Laptop Gamer",
  "precio": 15000.00,
  "stock": 10,
  "categoriaId": 1
}

### 4. PUT - Actualizar producto por ID
PUT http://localhost:3000/api/producto/7
Content-Type: application/json

{
  "nombre": "Laptop Gamer Pro",
  "precio": 16500.00,
  "stock": 12,
  "categoriaId": 1
}

### 5. DELETE - Eliminar producto por ID
DELETE http://localhost:3000/api/producto/7

### 2. GETALL - Obtener todas las ventas
